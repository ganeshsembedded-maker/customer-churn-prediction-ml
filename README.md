# Customer Churn Prediction using Logistic Regression

## 📌 Description
Built a machine learning model to predict customer churn using telecom data.
Performed EDA, feature engineering, correlation-based feature selection,
and trained a Logistic Regression model.

## 🛠️ Technologies
- Python
- Pandas, NumPy
- Matplotlib, Seaborn
- scikit-learn

## 📈 Results
- Accuracy: ~80%
- Logistic Regression with correlation-based feature selection
